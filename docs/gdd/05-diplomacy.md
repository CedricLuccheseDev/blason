# 05 — Diplomacy

Figures: `docs/RULES.md` (Alliances and traitors).

## D-DIP-1: Short alliances, renewed or left to lapse

- Status: Accepted
- Owner: Cédric
- Updated: 2026-10-28
- Links: P1, P4
#### Why?
- Need: alliances that matter without freezing the map.
- Evidence: OpenFront's 5-minute alliances with a renewal prompt (code read
  27/10).
#### How?
- An offer is a herald's letter on the map, accepted or refused in one click;
  an alliance lasts 5 minutes and is renewed if both ask in its last 30 s.
#### What?
- Allies never strike each other; sealed, their armies against each other go
  home. Left to run out, no traitor.
#### Validation
- Confidence: Preliminary.

## D-DIP-2: The traitor's mark

- Status: Accepted
- Owner: Cédric
- Updated: 2026-10-28
#### Why?

#### What?
